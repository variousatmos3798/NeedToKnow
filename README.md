# NeedToKnow

**YouTube Tutorial Generator & Refiner** - Transform long YouTube tutorials into concise, actionable step-by-step guides. Import multiple videos on the same topic, and watch as AI continuously refines and improves the tutorial.

## 🎯 Problem It Solves

Instead of watching hour-long YouTube tutorials, get instant step-by-step instructions. Add multiple videos on the same topic, and the AI will synthesize the best approach from all sources.

## ✨ Key Features

- 📹 **Import YouTube URLs** - Extract transcripts automatically
- 🤖 **AI-Powered Processing** - Convert transcripts to actionable steps
- 🔄 **Continuous Refinement** - Add more videos to improve tutorials
- 📚 **Topic Management** - Organize videos by concept
- 📝 **Export Tutorials** - Save guides in multiple formats
